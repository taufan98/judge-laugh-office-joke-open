A program that writes one original funny line about office life to
`/output/entry.txt` — an entry for
[Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232)
on make.fun. A house judge compares the lines pairwise: a setup everyone in
an office recognises, a punchline that turns it back on itself, and economy
of words.

## The line

> I blocked my calendar as 'focus time' and my boss booked over it with a meeting called 'quick sync about focus time.'

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (117 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
